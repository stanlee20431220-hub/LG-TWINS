# LG TWINS 재고 모니터링

GitHub Actions에서 상품을 조회하고 Google Sheets에 옵션별 결과를 저장합니다. 텔레그램에는 중요한 변동 요약과 시트 링크만 전송합니다. 시트 연결이 실패하면 기존 전체 알림 방식으로 자동 대체합니다.

## 실행
- 매일 한국 시간 09:15 예약 실행 (GitHub 상황에 따라 지연될 수 있음)
- Actions > Twinscorestore Stock Check > Run workflow에서 수동 실행 가능
- 동시 실행은 순서대로 처리합니다.

## 필요한 Actions Secrets
- TELEGRAM_BOT_TOKEN
- TELEGRAM_CHAT_ID
- GOOGLE_SERVICE_ACCOUNT_JSON: 서비스 계정 JSON 전체. 저장소 파일에는 절대 넣지 않습니다.
- GOOGLE_SHEET_ID: 전용 스프레드시트 ID

Google Cloud에서 Sheets API를 활성화하고 서비스 계정 이메일을 전용 시트의 편집자로 공유합니다. 서비스 계정에 Cloud 프로젝트 관리자/편집자 역할은 필요하지 않습니다.

## 데이터 해석
- 옵션 하나당 한 행: 상품명, 옵션, 수량, 상품 링크, 이미지, 확인 시각, 이전 수량, 증감, 상태, 가격, 출처
- 확인불가(-1): 조회 실패이며 품절로 간주하지 않습니다.
- 선택가능·수량 미확인(-2): 주상품 옵션에서 선택 가능하거나 1개 수량 계산이 성공했지만 수량을 확정하지 못한 상태입니다. 구매 성공이나 재고 수량을 보장하지 않으며 증감·품절·재입고 비교에서 제외됩니다.
- 서버가 상품 옵션에 대해 반환한 유효한 재고값(stock_number)을 우선 사용합니다. 일시적인 네트워크·HTTP·JSON 오류는 최대 3회 재시도하고, 확정값이 없을 때만 주문 가능 수량을 계산합니다. 계산 중 오류가 나면 추정치를 정확한 수량처럼 저장하지 않습니다.
- 주문 가능 상한: CalculatorProduct가 해당 수량 주문을 허용했음을 뜻하며 실제 창고 재고가 아닙니다.
- 오류·이전 데이터: 새 조회가 실패하여 마지막 기록을 유지한 행입니다.
- 누락된 이미지나 외부 이미지 접근 제한 시 썸네일이 표시되지 않을 수 있습니다.
- 증감은 판매량이 아닙니다. 신규 옵션 및 불확실한 값은 비교하지 않습니다.
- 첫 시트 저장은 기준 데이터 설정이며 이후 실행부터 변경을 비교합니다.

시트의 자동 관리 탭에는 수동 데이터를 넣지 마세요. 수동 메모는 별도 탭에 보관하세요.
